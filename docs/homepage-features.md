# 개인 홈페이지 기능 5가지 — Ultrathink 분석

> **현재 스택**: 순수 HTML/CSS/JS + localStorage (서버 없음)
> **목표**: 이 스택 안에서 최대한 가치 있는 기능 설계

---

## 기능 1. 자기소개 히어로 섹션 (Hero / About)

**목적**: 방문자가 3초 안에 "이 사람이 누구인지"를 파악하게 만드는 첫인상

### 핵심 구성요소

| 요소 | 역할 |
|---|---|
| 프로필 사진 | 신뢰감 형성 (얼굴 없는 페이지는 익명처럼 느껴짐) |
| 이름 + 한 줄 태그라인 | "나는 ○○를 하는 ○○입니다" 형식 |
| 기술 스택 뱃지 | 말이 아닌 아이콘으로 즉시 전달 |
| CTA 버튼 | "포트폴리오 보기" / "연락하기" |

### 기술적 판단

```
타이핑 애니메이션 (Typed.js 라이브러리 or 순수 JS 구현)
→ "저는 개발자입니다" → "저는 디자이너입니다" 자동 전환
→ 단 30줄이면 구현 가능, 시선을 끌어당기는 효과 큼
```

### 트레이드오프

- ✅ 구현 난이도 낮음, 효과 최대
- ⚠️ 태그라인을 너무 길게 쓰면 역효과 — **한 문장, 10단어 이내**가 황금률
- ⚠️ 사진 없으면 신뢰도 20~30% 하락 (통계적 사실)

**구현 우선순위**: ★★★★★ (가장 먼저 만들어야 할 것)

## 기능 2. 프로젝트 포트폴리오 카드 갤러리

**목적**: "말하지 말고 보여줘라" — 실제 작업물로 능력을 증명

### 핵심 구성요소

```
[프로젝트 카드 구조]
┌──────────────────────┐
│   스크린샷 / 썸네일   │
├──────────────────────┤
│  프로젝트 이름        │
│  한 줄 설명           │
│  [기술 태그] [기술 태그]│
│  [GitHub] [데모 보기] │
└──────────────────────┘
```

### 기술적 판단

- CSS Grid `auto-fill` + `minmax(280px, 1fr)` → 화면 크기에 따라 자동으로 열 수 조정
- 카테고리 필터 버튼 (전체 / 웹 / 앱 / 디자인) → 현재 Todo 앱의 필터 탭 구조 **그대로 재활용 가능**
- 이미지 `loading="lazy"` 속성 → 스크롤 내릴 때만 로드, 속도 개선

### 깊은 분석

> 채용담당자/클라이언트는 포트폴리오 페이지에서 평균 **6초**만 머문다.
> → 카드 하나당 즉시 이해되어야 함 (설명 50자 이내)
> → 프로젝트 수보다 **질** 중요 (3개의 완성도 높은 것 > 10개의 미완성)

### 트레이드오프

- ✅ 구체적 증거 → 신뢰도 폭발적 상승
- ⚠️ 썸네일 이미지 없으면 카드가 허전함 → 색상 그라디언트 배경으로 대체 가능
- ⚠️ 오래된 프로젝트 방치 시 "관리 안 하는 사람" 인상

**구현 우선순위**: ★★★★★

## 기능 3. 다크 / 라이트 테마 토글

**목적**: 사용자 선호도 존중 + 눈의 피로 감소

### 기술적 핵심 (CSS 변수 활용)

```css
/* CSS 변수 = 색상을 한 곳에서 관리하는 저장소 */
:root {
  --bg: #f0f2f5;
  --text: #333;
  --card: #fff;
}

[data-theme="dark"] {  /* data-theme 속성이 dark일 때 */
  --bg: #1a1a2e;
  --text: #e0e0e0;
  --card: #16213e;
}
```

```js
// 버튼 클릭 시 테마 전환 + localStorage에 기억
function toggleTheme() {
  const isDark = document.documentElement.dataset.theme === 'dark';
  document.documentElement.dataset.theme = isDark ? 'light' : 'dark';
  localStorage.setItem('theme', isDark ? 'light' : 'dark');
}
```

### 깊은 분석

> 2024년 기준 스마트폰 사용자의 **81.9%**가 다크 모드를 기본 사용
> → 다크 모드 없는 홈페이지 = 대부분의 방문자에게 눈이 부신 경험
> → 현재 Todo 앱의 보라색 그라디언트 (`#667eea → #764ba2`)는 다크 모드에서도 잘 어울림

### 트레이드오프

- ✅ 구현 30분, 효과는 영구적
- ✅ `prefers-color-scheme: dark` 미디어 쿼리로 OS 설정 자동 감지도 가능
- ⚠️ CSS 변수를 처음부터 쓰지 않으면 나중에 적용이 어려움 → **지금 리팩토링하면서 적용 권장**

**구현 우선순위**: ★★★★☆

## 기능 4. 블로그 / 학습 기록 섹션

**목적**: SEO 최적화 + 방문자의 재방문 유도 + 성장 과정 기록

### 두 가지 구현 전략 비교

| 전략 | 방법 | 장점 | 단점 |
|---|---|---|---|
| **A안 (초간단)** | JS 배열에 글 목록 하드코딩 | 서버/DB 불필요 | 글 추가 시 코드 수정 필요 |
| **B안 (추천)** | `marked.js` 라이브러리로 `.md` 파일 파싱 | 마크다운으로 편하게 작성 | fetch API 필요 (로컬에서 일부 제한) |

### A안 예시 (서버 없이 즉시 구현 가능)

```js
const posts = [
  { date: '2026-05-06', title: 'Todo 앱 만들기', tags: ['HTML', 'JS'], summary: '...' },
  { date: '2026-04-20', title: 'CSS Grid 정복', tags: ['CSS'], summary: '...' },
];
```

### 깊은 분석

> 블로그 있는 개인 홈페이지는 없는 것보다 Google 검색 노출 **10배** 증가
> → 검색엔진은 "살아있는 콘텐츠"를 좋아함
> → 단, **꾸준함이 관건**: 2개월 방치된 블로그는 오히려 역효과

### 트레이드오프

- ✅ SEO · 방문자 재방문 · 개인 브랜딩 동시 달성
- ⚠️ 콘텐츠 없으면 섹션 자체가 민망함 → **최소 3~5편 작성 후 공개**
- ⚠️ 순수 HTML에서 마크다운 파싱은 약간 복잡 → Notion/GitHub Gist 임베드로 우회 가능

**구현 우선순위**: ★★★☆☆ (콘텐츠 준비 후 구현)

## 기능 5. 연락처 + SNS 허브

**목적**: 방문자를 "기회"로 전환하는 마지막 관문

### 핵심 설계 원칙

```
방문자의 행동 심리:
  홈페이지 봄 → 관심 생김 → 연락하려 함 → 방법 못 찾음 → 떠남
                                                         ↑ 이 지점에서 기회 소멸
```

### 구현 옵션 3가지

| 옵션 | 방법 | 비용 | 난이도 |
|---|---|---|---|
| mailto 링크 | `<a href="mailto:email@gmail.com">` | 무료 | 매우 쉬움 |
| FormSubmit | `action="https://formsubmit.co/email"` 서비스 | 무료 | 쉬움 |
| Netlify Forms | Netlify 배포 시 자동 지원 | 무료(제한) | 보통 |

### SNS 허브 구조

```
[GitHub] [LinkedIn] [이메일] [블로그] [Instagram]
    아이콘 + hover 애니메이션으로 직관적 표현
    Font Awesome 또는 SVG 아이콘 사용
```

### 깊은 분석

> 연락처가 없는 홈페이지는 잠긴 가게와 같음
> → 이메일 주소를 평문으로 노출하면 스팸봇이 수집 → **난독화** 권장

```js
// 스팸봇 방지: JS로 동적 생성 (봇은 JS를 실행 못함)
const email = ['hg.cheon002', 'gmail.com'].join('@');
```

### 트레이드오프

- ✅ 구현 난이도 최하, 기회 비용은 최대
- ⚠️ 이메일 평문 노출 시 스팸 증가 → JS 동적 조합 또는 이미지로 표시
- ⚠️ SNS 링크가 너무 많으면 분산됨 → **2~3개 핵심 채널**에 집중

**구현 우선순위**: ★★★★★

## 종합 로드맵

```
1단계 (오늘)      → 연락처 + SNS 허브          [30분, 최대 기회비용]
2단계 (이번 주)   → 히어로 섹션 + 다크모드      [3~4시간]
3단계 (다음 주)   → 프로젝트 갤러리              [4~6시간]
4단계 (콘텐츠 후) → 블로그/기록 섹션             [준비 완료 후]
```

## 현재 Todo 앱의 자산 재활용 포인트

| 기존 코드 | 재활용 방법 |
|---|---|
| 필터 탭 UI | 포트폴리오 카테고리 필터로 재사용 |
| localStorage 패턴 | 테마 저장, 방문 횟수 기록에 재사용 |
| 보라색 그라디언트 디자인 | 전체 홈페이지 브랜드 컬러로 통일 |
